# 独立实现记录

## 目标

本仓库是依据仓库所有者提供的产品需求重新实现的独立工程。不得把其他本地或远程项目的文件复制到本仓库，也不得逐行移植、机械转换或直接导入其他项目代码。

## 工作边界

规格工作可以把外部可观察行为记录为事实，例如请求顺序、字段名称、响应结构、状态变化和错误条件，但不得在本仓库中放入其他实现的源码片段、特征性注释、内部类结构或复制的说明文字。

实现工作只接收产品规格和协议规格，并独立选择模块结构、命名、算法、界面组合、测试夹具、提示文字和错误处理方式。

## 允许使用的输入

- 仓库所有者提供的需求和截图。
- 仓库所有者正常操作服务时观察到的行为。
- 经仓库所有者授权记录的公开平台响应和浏览器网络元数据。
- Python、Qt、HTTP 和依赖库的公开文档。

## 证据要求

每个远程操作都必须在实现前写入[远程协议规格](PROTOCOL_SPEC.md)。测试使用本项目重新编写的合成响应。在实际可行时，规格变化和实现变化应使用独立提交记录。
