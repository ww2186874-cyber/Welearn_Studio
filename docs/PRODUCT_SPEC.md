# 产品规格

## 产品形态

WeLearn Studio 是优先面向 Windows 的桌面工作台。主窗口采用协调统一的深色三栏布局：

1. 账号列表和账号任务状态。
2. 课程、单元选择、任务参数、进度、开始和停止操作。
3. 运行概览和完整结构化日志。

切换账号时，右栏保持当前宽度不变。窗口较窄时，右栏可以通过明确的按钮折叠。界面缩放支持 `80%` 至 `200%`，设置保存在本机；支持 `Ctrl+鼠标滚轮` 调整，并可用 `Ctrl+0` 恢复 `100%`。

## 账号与课程

- 支持添加、导入、删除和搜索账号。
- 账号包含用户名、可选昵称、运行状态和独立服务会话。密码属于运行时数据，不是工作区设置。
- 账号状态使用不同颜色区分：待处理、已登录、刷作业中、刷时长中、请求已接受、部分结果未知、已停止和错误。
- 恢复上次选择的账号文件路径和课程。
- 切换当前可见账号时，其他账号的任务保持独立运行。

## 单元与小课

- 按服务器返回顺序显示课程单元，包括复选框、名称、可运行小课数量、选择摘要和小课设置按钮。
- 没有可运行小课的单元必须禁用并显示为暗淡状态。
- 点击整行可以切换单元选择。
- 支持按单元编号或名称搜索。筛选项为全部、已选择、未选择、不可运行和加载失败；全选与全不选固定显示在筛选菜单外部。
- 小课选择窗口一次只显示一个单元，支持搜索、全选和全不选，并默认选中全部可运行小课。
- 每个账号和课程分别记住小课选择。

## 任务模式

主分段控件用于选择刷作业或刷时长，两种模式共用当前选择的单元和小课。

任务参数采用对齐的“标签、数字输入框、单位”三列结构。数字输入框内只显示数字，右侧提供上下排列的大尺寸增减按钮。参数区域高度随当前模式的可见内容变化。

刷作业参数：

- 正确率为 `0` 至 `100` 的整数百分比。

刷时长参数：

- 请求总时长范围为 `1` 至 `72` 小时。
- 随机扰动使用整数分钟。
- 并发数范围为 `1` 至 `100` 个小课任务。
- 总时长以整分钟平均分配给所有已选的可运行小课，不能整除的余数直接舍弃。
- 随机扰动在整分钟分配前只对总计划应用一次；任何小课的分配时长不得少于 `1` 分钟。
- 如果有效总分钟数少于已选可运行小课数，系统必须阻止启动并明确记录“总时长不足”，不能为了满足最低一分钟而静默增加请求时长。
- 运行概览分别显示整数分配后的平台有效时长、舍弃的余数和并发排程预计耗时，以区分平台可记录时长和并发大于一时的实际等待时间。
- 预计耗时与运行时使用同一套并发排程算法。

并发数表示同时处于活动状态的小课任务数量，不是账号数量。

## 运行行为

- 任务启动后，计划保持不可变。
- 每个请求都必须得到已接受、已拒绝、未知或已取消中的一种明确结果。“已接受”只表示接口接受请求。
- 长时间等待支持协作式取消。停止操作会阻止未开始工作、打断等待，并在不强制终止的情况下回收工作线程。
- 进度表示“已经开始且到达最终结果的请求数 / 计划请求数”。因快速失败而从未开始的工作不显示为已处理。
- 请求按固定批次运行，每批最多使用配置的并发数。当前批次的所有请求结束后，下一批才会开始。日志为每批记录一条简洁的开始信息和一条结束摘要；活动小课名称及计划分钟数只在该批运行时显示。
- 某个小课返回拒绝或未知结果后，系统停止剩余队列，并协作式取消仍在运行的请求，避免同一协议错误快速影响全部小课。
- 日志包含结构化严重级别、时间、范围和简明说明。

## 持久化与课程预设

- 使用稳定标识按账号和课程保存非敏感设置。
- 保存已选课程、单元、小课、任务模式、正确率、总小时数、随机分钟数、并发数和界面缩放。
- 课程预设是当前课程页面的完整快照，包括任务参数、已选单元和已选小课。
- 预设与课程绑定并在本机账号间共享，可以在统一配置窗口中保存、应用、重命名和删除。
- 应用预设时先按稳定标识匹配，再按完整名称匹配；不存在的项目直接跳过，不能错误映射到其他内容。
- 恢复默认配置是主窗口中的独立操作，只影响当前账号和当前课程。

## 首个里程碑明确不包含的功能

- 读取平台报告的累计小课时长或完成状态。
- 定时调度未来任务。
- 在工作区偏好设置中保存密码。
- 在自动化测试中访问真实服务。
